# janitor

Clean up your packages as oneshot.

janitor will clean ups...

- `vendor/`
- `node_modules/`
- `.venv`
- `venv/`
- `env/`

## How to use

```shell
# dry run
./janitor.sh --dry-run

# execute
./janitor.sh

# execute specific directory
.janitor.sh /path/to/directory
```
